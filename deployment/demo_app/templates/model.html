Four-agent control path

Preprocess → infer → validate → explain

01
Data preprocessing

Checks file integrity, dimensions, brightness, contrast, and required structured fields.

02
Model inference

Runs only the model matching the declared modality and returns class scores without workflow priority.

03
Safety validation

Flags low confidence, unsupported inputs, and public-sample limits; always requires clinician review.

04
Explanation & reporting

Presents plain-language scope and limitations. It never generates a treatment instruction.

Archived baselines and synthetic pipeline checks

The previous synthetic models remain available only in the clearly marked simulation lab. Their 100% synthetic scores are not presented as human-data evidence.

The earlier fundus V3 four-class baseline remains available for compatibility: 72.53% accuracy and 66.03% Macro-F1 on 91 held-out images. It is a separate fundus task, not cataract grading.
